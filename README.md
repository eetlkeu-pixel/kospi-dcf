# 코스피 사이클 DCF

코스피 적정 시가총액을 **업사이클 이익**과 **정상 이익**으로 나눠 할인하고, 내러티브별 변화(Δ)에 **반사성 승수**를 곱해 상·하방 범위를 추정하는 단일 페이지 계산기입니다.

- `index.html` 하나로 동작합니다 (외부 라이브러리 없음). 브라우저로 열거나 GitHub Pages로 게시하면 됩니다.
- 기본값은 `index.html` 상단의 `<script type="application/json" id="config">` 블록에 있습니다. 내러티브를 바꿀 때는 이 JSON만 고치면 됩니다.
- 페이지에서 고친 값은 브라우저에 저장되며, "설정 JSON 복사"로 내보낼 수 있습니다.

## 모델

```
PV       = Σ E_t/(1+r)^t + (반도체 NE + 비반도체 NE)·PER/(1+r)^N
r        = 국고채 10년 + 주식 위험 프리미엄
Δ        = PV(베이스 + 내러티브 Δ) − PV(베이스)
m        = 1/(1 + φ − ψ)
반사성 적정 = PV(베이스) + m·Δ,  극단 = PV(베이스) + m·Δ·(1+κ)
```

기준일 2026-11-18. 분석 도구이며 투자 권유가 아닙니다.
